# Hi, I'm Ranjan Singh 👋
### Gen AI & Product Engineer | Open-Source Maker

⤷ I'm Lead Engineer at Telos, with nearly a decade of experience shipping production AI and user-facing systems, hopelessly in love with TypeScript, React Native, and pushing the boundaries of system architecture. I specialize in building high-performance applications and crafting clean, modern user experiences. 

Whether I'm designing complex LangGraph workflows, focusing on agent adherence in multi-agent orchestration, or setting up detailed growth analytics, my goal is always to build scalable, high-impact software. ### 🛠️ What I'm Building

* **[Omit](https://omitsys.com):** A suite of Windows apps that detect and redact PII entirely on-device. No cloud, no accounts, no telemetry. It grew out of the privacy-by-design pipeline I built at Telos with Microsoft Presidio, and it's releasing soon.
* **[Shelly](https://github.com/ranjandsingh/shelly):** A minimalist, cross-platform terminal utility that optimizes AI coding workflows with a floating "notch" UI and live Claude Code status tracking.
* **[Telos](https://heytelos.com):** An AI life coach and journaling platform. Multi-agent LLM system on LangChain and LangGraph, with long-term memory via Zep and retrieval grounded in pgvector.

---

### 📦 Open Source

* **[sharp-multer](https://www.npmjs.com/package/sharp-multer):** Multer storage engine that uses Sharp to auto-optimize and resize uploads (JPG / PNG / WebP) on the fly.
* **[rn-tour-copilot](https://www.npmjs.com/package/rn-tour-copilot):** React Native walkthrough library with a fully customizable tooltip UI, pre- and post-step hooks, and better multi-step navigation.
* **[rn-country-code-picker](https://www.npmjs.com/package/rn-country-code-picker):** Lightweight, easy-to-use country code picker for React Native.
* **[markdown-preview-skill](https://github.com/ranjandsingh/markdown-preview-skill):** Offline live-reload Markdown preview for Claude Code, with GitHub dark theme and Mermaid support.
